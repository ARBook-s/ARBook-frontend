## Завершение (из инструкции Фонда)

1. Галочка **согласие на обработку персональных данных**.  
2. **Сохранить**.  
3. **Завершить редактирование** (статус «Сохранена»).  
4. **Подписать печатную форму** (квалифицированная ЭЦП).  
5. **Отправить**. Статус: «Отправлено на проверку».  
6. Бумагу в ЦИТиС **не** отправлять. Срок регистрации около **10 рабочих дней**.  
7. После штампа: Действия → Просмотреть → вниз → **Сформировать файл печатной формы**.  
8. Эту форму со штампом вставить в кабинет ФСИ: «Зарегистрированная Форма направления сведений о созданном РИД» → **Подать**.

### Если ошибка «Исполнитель — не все обязательные поля»

Сервисы → Пользователь → Управление ролями → Активная роль → Редактировать → заполнить **ИНН, СНИЛС, гражданство** → сохранить → отправить на проверку → приложить фото ИНН и СНИЛС → дождаться «Подтверждена» → перезайти → если карта не обновилась, **удалить черновик и создать ИКР заново**.
