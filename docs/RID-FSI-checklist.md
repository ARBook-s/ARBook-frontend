# Что сделать по РИД (ИКР) для ФСИ / gisnauka.ru

Ниже — **ваши** шаги. Агент не может: войти в Госуслуги, подать заявку в Роспатент, внести СНИЛС, подписать ЭЦП, нажать «Подать» куратору.

Подходящий вид РИД для ARBook: **программа для ЭВМ** (не патент на изобретение и не БД, пока нет отдельной регистрируемой базы как самостоятельного объекта).

Патент на «гибридный SLAM с точностью 0,5 см» **сейчас подавать нельзя**: в коде этого нет. Регистрируйте то, что существует: WebAR-приложение ARBook.

## Задачи, которые делаете только вы

### 0. Реестр авторов (до любых форм)

1. Зайти на [gisnauka.ru](https://gisnauka.ru) как физлицо через **Госуслуги (ЕСИА)**.
2. Блок **Сервисы → Сквозная прослеживаемость → Реестр авторов**.
3. Внести себя и **всех авторов программы** (кто писал код / имеет авторство).
4. Указать **СНИЛС**. Подтверждение в СФР идёт автоматически.
5. Дождаться статуса, что ФЛ подтверждено. Без этого формы ИКР не примут.

То же для научного руководителя и руководителя организации, если они фигурируют в отчёте.

### 1. Заявка в Роспатент на программу для ЭВМ

Подать через [ФГИС «Роспатент» / Госуслуги](https://new.fips.ru) или кабинет ФИПС.

Состав (типовой):

- заявление о государственной регистрации программы для ЭВМ;
- реферат (до ~900 знаков, на русском);
- депонируемые материалы: фрагмент исходного текста (обычно первые и последние листы, объём по актуальной инструкции ФИПС) **без секретов** (вырезать `.env`, пароли, ключи);
- согласие авторов на указание в реестре (если авторов несколько);
- документ об уплате пошлины;
- если права у организации — договор / служебное произведение.

**Подтверждающий документ для gisnauka:** для программы для ЭВМ Роспатент **не шлёт** «уведомление о поступлении». Срок 30 рабочих дней считают **с даты отправки заявки**. К ИКР прикладывают **скан поданной заявки**.

Черновик названия, реферата и признаков программы — в файле `docs/RID-programma-EVM-chernovik.md`.

### 2. ИКР РИД на gisnauka.ru (после отправки в Роспатент)

Путь (как в письме Фонда):

**Сервисы → Сквозная прослеживаемость → Информационные карты → Создание → Интеллектуальная деятельность → Результаты → создать РИД (вне рамок НИОКТР)**

Заполнить карту (подставить свои данные, черновик полей — ниже в том же файле), **подписать ЭЦП**, отправить на проверку в ЕГИСУ НИОКТР / ЦИТиС.

Дождаться формы **со штампом** в личном кабинете.

### 3. Форма ФСИ «Зарегистрированная Форма направления сведений о созданном РИД (ИКР)»

Когда на gisnauka.ru появится ИКР со штампом:

1. Открыть форму Фонда (в личном кабинете ФСИ / УМНИК).
2. Вписать номер ИКР, дату, вид РИД «программа для ЭВМ», рег. данные заявки ФИПС.
3. Нажать **«Подать»**.
4. Ждать куратора.

## Рекомендуемый порядок на этой неделе

1. Список авторов + СНИЛС → Реестр авторов gisnauka.ru.  
2. Дописать ФИО в черновик РИД, вырезать секреты из фрагмента кода.  
3. Оплатить пошлину, подать заявку в Роспатент, сохранить скан + дату отправки.  
4. В течение 30 раб. дней — ИКР на gisnauka.ru, ЭЦП.  
5. После штампа — форма ФСИ «Подать».
